06

Motion Semantics
ring-pulse
Agent 선택 시 보라색 링 확장. 관심 집중 신호.
ring-pulse-critical
Critical 상태 빨간 링. 긴급 상태 경보.
missing-flicker
MISSING Agent opacity 교란. 존재 불확실성 표현.
path-dash
SVG stroke-dashoffset 흐름. Agent 이동 경로 추적.
float-up
translateY + opacity 진입. 모달, 알림 등장.
EVENT
footprint-fade
발자국 아이콘 점진 소멸. Agent 이동 흔적.
event-glow
Event 영역 금빛 glow 맥동. Magic Event 활성화.
dissolve-out
opacity·blur·scale 소멸. Agent 퇴장 연출.
